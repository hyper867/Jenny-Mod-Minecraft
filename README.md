# Jenny Mod for Minecraft

Enhance your Minecraft world with the Jenny Mod, a popular community-created modification that introduces a unique and interactive companion character, Jenny. This mod focuses on adding a layer of social interaction, custom animations, and engaging NPC mechanics to the classic sandbox experience.

**[⬇️ Download Jenny Mod](https://github.com)**

## ✨ Key Features

* **Interactive Companion:** Adds Jenny, a fully animated NPC with her own personality and unique interactions.
* **Custom Animations:** Features high-quality, fluid animations that bring the character to life within the Minecraft art style.
* **Dialogue System:** Engage in conversations and interact with the mod's character to unlock different activities.
* **Companion Gameplay:** Experience a new way to populate your world with a companion that follows and interacts with the player.
* **Mod Compatibility:** Designed to run alongside other popular Minecraft mods for a fully customized gameplay experience.

## 🛠️ Installation Guide

Follow these steps to get the Jenny Mod running on your PC:

1. **Install Minecraft:** Ensure you have the version of Minecraft installed that is compatible with the mod.
2. **Install Minecraft Forge:** This mod requires **Forge**. Download and install the version of Forge that matches your game version.
3. **Download the Mod:** Get the latest mod file from the **[Download Link](https://github.com)**.
4. **Locate the Mods Folder:** 
   - Press `Win + R`.
   - Type `%appdata%` and press Enter.
   - Open `.minecraft` $\rightarrow$ `mods`.
5. **Add the Mod:** Drag and drop the downloaded `.jar` file into the `mods` folder.
6. **Launch Game:** Open the Minecraft Launcher, select the **Forge** profile, and click **Play**.

## 📋 Requirements
